# Eta 自定义推理强度设计

## 目标

让 Eta 能新增内置列表之外的推理强度原始值，并把这些值同步到每个模型的推理强度候选列表。自定义值在候选列表中的位置可配置为最前或最后；请求发送时保持用户输入的原始字符串。

## 非目标

- 不自动为所有模型勾选新加的自定义强度；只让它成为可勾选项，现有逐模型配置保持不变。
- 不修改上游基线或包名，继续使用 io.github.mangi.eta。
- 不为没有命名强度字段的供应商臆造数值预算映射。

## 约束

- 当前 ReasoningEffort 是八项封闭枚举，新增任意字符串必须改成可承载原始值的类型。
- 会话、默认强度、子代理、浮窗助手、标题生成等位置都以 wireValue 持久化。
- 模型能力解析、远端目录解析、模型设置页和聊天输入栏都从同一份候选列表取选项。

## 方案比较

1. 全局自定义列表：一处新增、所有模型可选、请求按原始值透传；改动最小，复用最方便。
2. 每个模型单独新增：语义最精确，但要在模型配置结构中重复存储并在两端重做配置界面。
3. 聊天栏单次自由输入：最轻量，但不能集中管理，也不能稳定同步到每个模型的候选列表。

选择方案一。新增的自定义值对所有模型可见；是否启用仍由每个模型自己的勾选决定。

## 数据设计

- 本地偏好 eta_agent_preferences 新增 agent_custom_reasoning_efforts，保存原始字符串数组，保留输入顺序。
- 新增 agent_custom_reasoning_effort_position，取值 first 或 last，默认 last。
- ReasoningEffort 改为开放值类型：已知强度仍是类型上的命名常量；任意非空、无空白字符串可作为自定义值。
- 自定义强度显示名就是原始值；内置强度继续显示本地化名称。

## 修改范围

- 设置页新增“自定义推理强度”管理入口，支持新增、删除和选择“放最前 / 放最后”。
- ProviderModelsTab 的候选列表合并内置强度与自定义强度，并按位置设置排序。
- ModelReasoningCapabilities 的候选、规范化与远端目录解析接受已保存的自定义值。
- ProviderReasoning 对命名强度字段继续写入原始值；需要数值预算的供应商只接受已有映射，未知自定义值给出明确错误而不是静默改写。
- 聊天栏、默认强度、子代理、浮窗助手和标题生成的选择器读取合并后的候选列表。

## 兼容与验证

- 旧会话中的未知字符串仍按原值读取，不显示为默认值。
- 删除自定义值不会破坏历史会话，只是不再出现在新选择器里。
- 单元测试覆盖：任意原始值解析、内置值不变、位置排序、模型候选同步、请求字段原样发送。
- 执行 gradlew :app:testDebugUnitTest 与 gradlew :app:lintDebug，再构建 Debug APK 并确认原包名与提示词开关未受影响。
